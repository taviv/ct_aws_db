Studies whose conditions get no exact ICD-10-CM code from the MeSH and text mappings are sent, with their protocol text (summary, detailed description, eligibility criteria), to an LLM that picks ICD-10-CM categories. A code is published only if the LLM's quote is found in the protocol. So far this has run for Phase 3 and Phase 2/3 studies.

How good are the codes?

Scorecard on 300 Phase 3 and Phase 2/3 studies that already had exact MeSH-derived codes, run blind (the LLM didn't see those codes):

  • 83% of studies: at least one LLM category agrees with the MeSH code
  • 72% of the MeSH categories were found by the LLM (recall)
  • 68% of the LLM's verified categories match a MeSH code (precision); 69% of those it would publish as exact
  • 26 of 414 codes were dropped because their quote wasn't found in the protocol

The MeSH codes aren't a true gold standard. Of the 51 studies with no agreement, a manual review found the LLM right and the MeSH code wrong in about 12, the LLM right but its quote rejected in about 9, both defensible in about 11, and the LLM wrong in about 19 (6% of the 300).

Method: Claude Haiku 4.5 on Amazon Bedrock, prompt v5, up to 12 categories per study. Every code needs a quote found in the protocol text. Catch-all categories (C76–C80, C96) are published as broad only, and LLM codes are never added to a study that already has an exact code.
